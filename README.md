
# QuizMaster Project

**QuizMaster** is a simple quiz web application that lets users test their knowledge with multiple-choice questions. It includes a timer, dynamic question display, and a leaderboard feature.

## Features

- **Start the Quiz**: Enter your name to start the quiz.
- **Timed Quiz**: A timer counts down during the quiz.
- **Multiple Questions**: Questions are presented with hints and answer choices.
- **Next Question Button**: After answering, click to proceed to the next question.
- **Leaderboard**: Top scores are displayed on the leaderboard.
- **Progress Bar**: A progress bar shows quiz completion.

## Technologies Used

- **HTML**: Structure of the web pages.
- **CSS**: Styling and layout.
- **JavaScript**: Logic for quiz operations (questions, timer, score, etc.).

## Setup and Installation

### Prerequisites

To get the project running locally, make sure you have the following installed:
- A modern web browser (Google Chrome, Mozilla Firefox, etc.)

### Steps to Run the Project

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/himanshu7437/Quiz-Master-Project.git
   ```

2. **Navigate to the Project Folder**:
   ```bash
   cd quizmaster
   ```

3. **Open `index.html` in your web browser**:
   - You can either double-click the `index.html` file or open it via your browser’s file explorer.
   - The app will be ready to use locally.
